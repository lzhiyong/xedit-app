XEdit 是一款 Android 代码编辑器，专为大型源文件的流畅体验而设计：8.8 MB、23.9 万行的 sqlite3.c 滚动、折叠、编辑都不掉帧。

<b>编辑</b>
<ul>
<li>文本存放在 piece tree 中，即 VS Code 文本缓冲区所用的数据结构</li>
<li>撤销与重做；重新打开文件时会恢复光标和编辑历史</li>
<li>自动换行、行号、缩进参考线、颜色值预览</li>
<li>代码折叠、括号匹配、可配置的自动补全括号对</li>
<li>支持正则表达式的搜索与替换</li>
<li>跳转到行，并预览目标行</li>
<li>悬浮选择栏、双指缩放、拖动选区手柄时的放大镜，以及键盘上方的额外按键行</li>
<li>多标签页、侧边栏文件树、只读与编辑模式</li>
</ul>

<b>语法高亮</b>
<ul>
<li>基于 tree-sitter 的语法高亮，在后台线程计算，输入从不等待高亮</li>
<li>高亮主题（内置 astrodark 与 astrolight）</li>
</ul>

<b>语言服务器（LSP）</b>
<ul>
<li>可连接你自己配置的服务器，如 clangd、pyright、lua-language-server（应用本身不内置服务器）</li>
<li>补全、诊断、悬停信息、签名提示、转到定义、查找引用、重命名、代码操作、格式化与大纲</li>
<li>服务器可在 Termux 中启动；没有服务器时，会补全文本中出现过的单词</li>
</ul>

<b>控制台</b>
<ul>
<li>显示应用和语言服务器的输出、问题列表，以及构建页：在 Termux 中运行命令，并从输出中识别 gcc、clang 和 Python 的错误</li>
</ul>

<b>外观</b>
<ul>
<li>浅色、深色、纯黑主题，支持系统动态取色</li>
<li>内置 JetBrains Mono 与 Source Code Pro，也可导入自己的字体；可调字号与制表符宽度</li>
<li>中英文界面</li>
</ul>

<b>稳定性</b>
<ul>
<li>Java 崩溃、原生崩溃和 ANR 会被捕获，并在独立进程中显示，可复制、导出或反馈</li>
</ul>

<b>须知</b>
<ul>
<li>文件通过存储访问框架（SAF）打开和保存；“所有文件访问”权限为可选</li>
<li>语法库、查询文件和主题不在 APK 中。首次启动时，应用会从项目的 GitHub 发布页下载（设置 → 语法高亮资源）</li>
</ul>
