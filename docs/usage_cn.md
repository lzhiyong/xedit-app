# 使用说明

> [X Editor](../README_cn.md) 文档 · [English](usage.md)

## 代码补全

补全的触发时机：输入服务器的触发字符（如 `.`、`->`、`::`）后立即请求；输入单词时，在短暂停顿后请求。继续输入时，列表在本地过滤。选中一项后，编辑器会：

- 替换当前单词；
- 展开代码片段，光标停在第一个跳转点并选中其中的占位内容；
- 对于服务器只发来函数名的情况（pyright、lua-language-server、typescript-language-server 默认如此），根据签名为每个必填参数生成占位，插入 `foo(a, b)`；不知道参数时插入 `foo()`，光标停在括号中间。在 import 行或后面已有 `(` 时不会这样做；
- 执行附加编辑，例如插入 `#include`；
- 如果补全内容末尾的闭合字符在光标后已经存在，会直接覆盖它而不是再插入一个（`#include <st|>` 选中 clangd 的 `stdlib.h>` 得到 `<stdlib.h>`，而不是 `<stdlib.h>>`）；补全内容自带的开头字符也同样处理。仍用于闭合前面括号的字符会保留，例如 `bar(foo()|)` 中的 `)`。

以上操作合并为一次可撤销的编辑。使用实体键盘时，方向键在列表中移动，Enter 或 Tab 选中，Esc 关闭。

和 nvim 一样，之后按 Tab 依次跳到下一个参数，最后跳到 `)` 之后（Shift+Tab 或长按符号栏的 Tab 返回上一个）。在填写参数时再选一个补全项，片段不会中断；如果选中的本身也是片段，先在它的参数间跳转，跳完再回到外层的下一个参数。

输入路径时会列出该处的文件（类似 cmp-path）：`./`、`../` 开头，引号中的路径（`#include "dir/`、字符串里的文件名），或 `/sdcard/Do` 这样的绝对路径；在 `#include "`、`src="` 之后还会直接列出文档同目录下的文件。相对路径从文档所在目录算起；选中文件夹后会接着列出其中的内容。没有所有文件访问权限时，应用按路径只能看到共享存储中的文件夹和媒体文件，因此会通过文件树中包含该目录的文件夹（用**添加文件夹**打开）来列出文件；单独打开的文件（**打开文件**）没有可用的文件夹，编辑器会提示一次。

文档大纲、代码操作和引用在底部面板中显示：每种类型带有对应颜色的标记，右侧显示行号，光标所在的符号（或位置）会被标出并自动滚动到可见处；大纲用引导线显示层级；代码操作按快速修复、重构、源代码操作分组，服务器推荐的项排在最前并带“推荐”标签；条目较多时提供筛选框。

## 注释

浮动栏 ⋮ 菜单中的**注释**会注释掉选中内容；没有选中时作用于光标所在行。如果已经是注释，则显示为**取消注释**。整行使用行注释（`//`、`#`、`--`），注释符加在缩进最少那一行的缩进处，空行不动；选中一行中的一部分时使用块注释（`/* … */`），没有行注释的语言（CSS、HTML）也使用块注释。整个操作是一次可撤销的编辑，选区仍覆盖处理过的内容。
